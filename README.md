# Thyme Machine

Thyme Machine is a Lebanese at heart dating experience built around taste, time, and cultural connection.

This repository currently contains a private MVP prototype. It is not connected to production accounts, payments, Apple, Google Play, or real user data.

## MVP concept

* Profiles built from food, culture, humor, and time based prompts
* A small daily discovery ritual instead of an infinite swipe feed
* Matches explained through shared “taste signals”
* A subscription layer that unlocks depth, not basic human connection
* Safety, reporting, blocking, and age gating designed in from the start

## Run locally

Open `prototype/index.html` in a browser. No build step or network connection is required.
